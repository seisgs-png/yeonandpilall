# 연앤필 총관리 대시보드 — 작업 명세서

밴드 연앤필(핵심 멤버 2명 + 세션 여러 명)의 일정·할일·회의록·정산을 폰에서 한눈에 보는 **읽기 전용** 웹 대시보드.
데이터 입력·수정은 전부 구글 시트에서 하고, 웹은 보여주기와 시트로 가는 링크만 담당한다.

---

## 1. 전체 구조

```
GitHub Pages (정적 HTML/CSS/JS · 읽기 전용 · 홈 화면 추가)
   │  GET ?token=...&scope=member
   ▼
Apps Script 웹앱 (토큰 확인 → 시트 읽기 → 행번호 계산 → JSON 응답)
   │
   ▼
구글 시트 「연앤필_총관리」  +  구글 드라이브 (원본 파일)
   ▲
   └─ 웹의 [수정] 버튼 → 해당 시트 탭(가능하면 해당 행)으로 이동
```

원칙
- 웹에서는 데이터를 쓰지 않는다. 쓰기 기능은 만들지 않는다.
- 데이터의 기준은 시트 하나뿐이다. 웹·스크립트에 데이터를 복사해 두지 않는다(캐시 제외).
- 빌드 도구 없이 순수 HTML/CSS/JS로 만든다. 프레임워크·npm 사용 안 함.
- 폰 화면(가로 360~430px)을 기준으로 먼저 설계하고, PC는 가운데 정렬된 최대 폭 480px로 보여준다.

## 2. 저장소 구조

```
/
├─ index.html
├─ style.css
├─ app.js
├─ config.js               # APPS_SCRIPT_URL만 들어감 (토큰 X)
├─ manifest.webmanifest
├─ icons/                  # 192px, 512px 아이콘
├─ apps-script/
│   └─ Code.gs             # 버전 관리용 사본. 실제 실행은 구글 Apps Script 편집기에 붙여넣어서
└─ README.md
```

- 무료 GitHub Pages는 **공개 저장소**가 된다. 저장소에는 토큰, 연락처, 시트 데이터를 절대 넣지 않는다.
- `config.js`의 Apps Script 주소는 공개돼도 된다(토큰 없이는 데이터가 안 나옴).

## 4. Apps Script 웹앱 (apps-script/Code.gs)

### 4-1. 배포 설정
- 시트에서 확장 프로그램 > Apps Script로 생성(시트에 연결된 스크립트).
- 배포 > 새 배포 > 웹 앱 · 실행 사용자: **나** · 액세스 권한: **모든 사용자**.
- 프로젝트 설정 > 스크립트 속성에 `TOKEN_MEMBER` 저장(길고 무작위한 문자열). 2단계에서 `TOKEN_SESSION` 추가.
- 토큰은 코드에 쓰지 않는다.

### 4-2. 요청
```
GET {APPS_SCRIPT_URL}?token={토큰}&scope=member
```
- 토큰이 틀리거나 없으면 `{ "ok": false, "error": "unauthorized" }` 반환. 데이터는 한 줄도 보내지 않는다.
- `scope=session`은 2단계(아래 8번)에서 구현. 1단계에서는 `scope=member`만.

### 4-3. 응답 (scope=member)
```json
{
  "ok": true,
  "updatedAt": "2026-11-01T14:03:00+09:00",
  "members": ["멤버A", "멤버B"],
  "links": { "sheet": "https://docs.google.com/...", "drive": "...", "etc": "..." },
  "gids": { "일정": 123, "할일": 456, "회의록": 0, "정산": 0, "공연장": 0, "아이디어": 0, "곡": 0, "세트리스트": 0 },
  "data": {
    "일정":   [ { "ID": "E002", "종류": "공연", "날짜": "2026-11-22", "시작시간": "19:30", "집합시간": "16:00", "장소": "...", "공연장ID": "V001", "메모": "...", "세션공개": "O", "_row": 3 } ],
    "할일":   [ ... ],
    "회의록": [ ... ],
    "정산":   [ ... ],
    "공연장": [ ... ],
    "아이디어": [ ... ],
    "곡":     [ ... ],
    "세트리스트": [ ... ]
  },
  "summary": { "monthIncome": 0, "monthExpense": 0, "commonBalance": 300000, "burden1": 30000, "burden2": 0, "transferText": "멤버B → 멤버A", "transferAmount": 15000 }
}
```

### 4-4. 처리 규칙
- 시트 주소·gid는 스크립트가 `SpreadsheetApp.getActive().getUrl()`, `sheet.getSheetId()`로 직접 구한다.
- `_row` = 실제 시트 행 번호(헤더가 1행이므로 데이터 첫 행이 2). 정렬·삭제로 바뀌어도 요청할 때마다 새로 계산한다.
- 날짜 칸 → `"yyyy-MM-dd"`, 시간 칸 → `"HH:mm"` 문자열로 변환. 시간대는 `Asia/Seoul`. (`Utilities.formatDate`)
- 숫자 칸(금액, 수용인원, 순서, BPM)은 숫자로, 나머지는 문자열(앞뒤 공백 제거).
- 빈 셀은 `""`.
- 내보내지 않는 것: 세션명단 탭 전체, 안내 탭, 설정 탭의 링크·이름 외 셀.
- 성능: `CacheService.getScriptCache()`에 응답 JSON을 60초 캐시. `&nocache=1`이면 캐시 무시(웹의 새로고침 버튼용).
- 응답은 `ContentService.createTextOutput(JSON.stringify(obj)).setMimeType(ContentService.MimeType.JSON)`.

## 5. 웹 화면

### 5-1. 공통
- 해시 라우팅: `#/`(홈), `#/schedule`, `#/todo`, `#/meetings`, `#/money`, `#/more`, `#/venues`, `#/ideas`, `#/setlist`.
- 하단 고정 탭바 5개: **홈 · 일정 · 할일 · 정산 · 더보기**. 더보기 안에 회의록·공연장·아이디어·세트리스트·바로가기.
- 표는 쓰지 않는다. 모든 목록은 세로로 쌓이는 카드.
- 글자 최소 15px, 버튼·카드 터치 영역 최소 44px 높이.
- 일정 종류 색: 공연 분홍 · 합주 파랑 · 회의 노랑 · 촬영 초록 · 기타 회색 (시트 조건부 서식과 맞춤).
- 다크 모드 대응(`prefers-color-scheme`).

### 5-2. 첫 방문 — 토큰 입력
- `localStorage`에 토큰이 없으면 토큰 입력 화면만 보여준다.
- 입력 후 한 번 요청해 `ok: true`면 저장하고 홈으로. 실패하면 "토큰이 맞지 않아요" 표시.
- 더보기 맨 아래에 [토큰 다시 입력] 버튼.
- `localStorage` 읽기/쓰기는 모두 `try/catch`로 감싼다(사파리 개인정보 보호 모드 등에서 실패 가능).

### 5-3. 홈(대시보드) 카드 순서
1. **다음 일정** — 오늘 이후(오늘 포함) 일정 중 날짜·시작시간 순 3개. 카드에 종류 배지, `11/22(토)`, 시작·집합시간, 장소. 일정 없으면 "잡힌 일정 없음".
2. **할일** — 상태가 완료가 아닌 것 중 ① 마감이 지난 것(빨간 표시) ② 7일 안에 마감인 것. 마감일 순. 위에 필터 칩 [전체] [멤버1] [멤버2] [같이]. 마지막 선택한 필터는 `localStorage`에 기억. 해당 없으면 "급한 할일 없음".
3. **정산** — 공용 잔액(크게), 이번 달 수입·지출, `transferText` + `transferAmount`. 금액 0이면 "정산할 금액 없음".
4. **최근 결정사항** — 회의록 날짜 최신 2건의 날짜·안건·결정사항. [회의록 문서] 버튼(문서링크가 있을 때만).
5. **바로가기** — 시트 열기, 드라이브 폴더, 기타 링크(설정 탭에 값이 있을 때만).
6. 맨 아래: "○분 전 갱신" + [새로고침] 버튼.

### 5-4. 목록 화면
| 화면 | 내용 |
|---|---|
| 일정 | 다가오는 일정 전체(날짜순) / [지난 일정 보기] 토글. 공연장ID가 있으면 공연장 이름 표시 |
| 할일 | 상태별 그룹(할일·진행·완료 접힘), 담당 필터 칩 |
| 정산 | 요약 카드 + 내역 최신순. 수입은 +초록, 지출·세션비는 −빨강. 정산완료 O는 흐리게. 영수증 링크 버튼 |
| 회의록 | 최신순. 결정사항 2줄까지 보이고 탭하면 펼침 |
| 공연장 | 이름·지역·수용인원·재섭외 별점. 탭하면 장비·조건·연락처·이력 펼침 |
| 아이디어 | 분류 필터 칩. 유튜브 링크면 썸네일(`https://img.youtube.com/vi/{영상ID}/hqdefault.jpg`), 그 외는 큰 [링크 열기] 버튼 |
| 세트리스트 | 공연(공연ID → 일정 이름·날짜)별로 묶어 순서대로. 곡명·키·BPM·길이, 악보·음원 버튼, 파트메모 |

### 5-5. 수정 링크
- 모든 카드 오른쪽 위에 작은 [수정] 버튼.
- 링크: `{links.sheet}#gid={gids[탭]}&range=A{_row}`.
- 시트 앱이 range를 무시하고 탭만 열 수 있다(정상으로 간주). 탭 단위 이동만 되면 합격.
- 링크는 새 탭으로 연다(`target="_blank" rel="noopener"`).

### 5-6. 데이터 불러오기
1. 화면을 열면 `localStorage`의 마지막 응답을 먼저 그린다.
2. 뒤에서 새로 요청 → 받으면 다시 그리고 캐시 교체.
3. 요청 실패 시: 캐시가 있으면 그대로 두고 상단에 "최신 데이터를 못 불러왔어요" 띠 + [시트 열기]. 캐시도 없으면 오류 안내와 [다시 시도].
4. [새로고침]은 `&nocache=1`을 붙여 요청.
5. 요청 중에는 갱신 시간 자리에 로딩 표시.

### 5-7. 홈 화면 추가
- `manifest.webmanifest`: name "연앤필", short_name "연앤필", display "standalone", start_url "./", 아이콘 192·512.
- iOS용 `apple-touch-icon`, `apple-mobile-web-app-capable` 메타 태그.
- 서비스 워커는 1단계에서 넣지 않는다(캐시 꼬임 방지). 오프라인은 5-6의 localStorage 캐시로 충분.

## 6. 보안 정리
- 공개 저장소에 토큰·연락처·데이터 없음.
- 토큰은 Apps Script 스크립트 속성에만 저장, 웹은 각자 폰의 localStorage에만 저장.
- 토큰이 새어 나가면 스크립트 속성 값을 바꾸고 둘 다 다시 입력.
- 세션명단은 어떤 scope로도 내보내지 않는다.

## 7. 작업 순서 (1단계)
1. 시트 템플릿을 구글 스프레드시트로 변환, 멤버 이름 입력, 예시 행 정리
2. `Code.gs` 작성 → 배포 → 브라우저 주소창에 `?token=...&scope=member`로 JSON 확인
3. GitHub 저장소 생성 → `config.js`에 웹앱 주소 → GitHub Pages(main 브랜치, 루트) 켜기
4. 토큰 입력 화면 → 홈 대시보드 → 목록 화면 순으로 구현
5. 두 사람 폰에서 홈 화면 추가 후 확인

### 완료 확인 목록
- [ ] 토큰 없이 웹앱 주소 열면 데이터가 안 나온다
- [ ] 시트에서 일정 추가 → 웹 [새로고침] 후 1분 안에 반영
- [ ] 시트에서 행 정렬을 바꿔도 [수정]이 올바른 탭(가능하면 행)으로 간다
- [ ] 마감 지난 할일이 빨간 표시로 홈 맨 위에 뜬다
- [ ] 정산요약 탭의 "보낼 사람 → 받을 사람"과 웹 정산 카드가 같다
- [ ] 비행기 모드로 열어도 마지막 데이터가 보인다
- [ ] 아이폰·안드로이드 홈 화면 추가 후 주소창 없이 열린다
- [ ] 가로 스크롤이 어느 화면에도 없다

## 8. 2단계 — 세션 전용 창 (나중에)
- 스크립트 속성 `TOKEN_SESSION` 추가, `scope=session` 처리.
- 내보내는 것: 오늘 이후 일정 중 세션공개=O(ID, 종류, 날짜, 시작시간, 집합시간, 장소), 세트리스트 중 세션공개=O + 연결된 곡의 곡명·키·BPM·길이·악보링크·음원링크, 공연장 중 세션공개=O의 이름·지역.
- 내보내지 않는 것: 정산, 정산요약, 할일, 회의록, 아이디어, 세션명단, 모든 메모·연락처 칸(파트메모 제외).
- 웹은 `session.html` 한 장: 다음 공연 카드 + 세트리스트. [수정] 버튼 없음.

## 9. 하지 않는 것
- 웹에서 데이터 쓰기·삭제, 로그인 시스템, 구글 폼 연동(필요해지면 별도 검토), 구글 캘린더 연동, 알림.
